# Series, guide and Taste refinements

## Product choices

- Home cards use compact `2 seas.` and a star rating, with scale-down rather than truncating the rating. Detail metadata keeps full wording.
- Seasons are directly visible, with one open at a time. Episodes and season trailers load on opening and remain cached for the details visit. Switching anchors the selected row in the existing scroll view. All returned episodes are available, without fetching other seasons.
- TV uses an icon-only favourite filter with an accessible tooltip, Notifications, a horizontal day strip and Now. Days stop before the final partial source day. A programme crossing midnight still appears on the preceding day; the window query uses interval overlap. The range describes the country feed's horizon, not a promise that every channel has continuous listings.
- Returning to Now previously reused mutated cached channel maps. Initial-window maps are now detached before later-window merge/eviction. Regression tests cover 30-hour forward navigation, reverse loading and cached Now.
- Taste has compact indented preferences inside groups, no duplicate topic dropdown, a styled portrait card and clearly expandable recommendation settings.
- A Taste portrait is optional and explicitly requested, never generated by ratings, Home loads, or opening Taste. GET only reads. POST uses the configured existing mini model, a bounded strongest-signal representation, a stable fingerprint and an atomic per-user daily lease. Repeated/unchanged calls reuse the saved paragraph. Failures allow retry after five minutes; the summary never controls ranking. A dated snapshot label explains that it is not live. Resetting Taste and deleting the account remove it.
- Warm paper is an optional device-persisted light palette beside cool blue. Dark colors are unchanged. The light palette now drives auth backgrounds, status/navigation bars and neutral icon/outline colors rather than mixing fixed colors from older themes.

## Verification

- Backend regression suite: 309 passing tests, including summary isolation, no-charge reads, concurrent-call suppression, daily limits, unchanged fingerprint reuse and account deletion cascade.
- Flutter: 109 tests pass; 22 opt-in checks skipped in the ordinary suite. Ten visual scenarios ran separately. Tests cover season switching/lazy requests, full-day boundaries, TV cache restoration, notification/favourite controls, palette persistence and light/dark text contrast. Analyzer and Android debug build pass.
- Rendered major screens in cool blue, warm paper, dark and large text. Inspected generated screenshots of Home, TV, Taste and season details.
- Applied additive `user_taste_summaries` migration; no existing ratings/preferences rewritten. No new provider or secrets shipped to Flutter.
- Production HTTP verification passed for summary generation/reuse, guide coverage and next-day windows (20 channels / 131 programmes), season counts, artwork and Chat persistence/clear. Disposable account deleted and session revoked. No private user account queried.
- Live synthetic AI review caught over-specific prose from sparse evidence; instructions were tightened to avoid inferred pacing/themes and preserve conditional exclusions. The paragraph remains a descriptive snapshot, not a recommendation rule.

Implementation reference: [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), using the app's existing validated structured-output wrapper and `store: false`.
